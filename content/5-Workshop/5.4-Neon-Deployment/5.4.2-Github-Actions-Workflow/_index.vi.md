### 5.4.2. Lấy file workflow GitHub Actions

1. Truy cập repo GitHub của dự án.
2. Mở đường dẫn `.github/workflows`.
3. Tải file `deploy.yml` về máy local hoặc dùng link GitHub tương ứng.
4. Kiểm tra file workflow trước khi dùng cho pipeline.
